# Bug hunt — 2026-10-19

Plugin 2.11.0 (main @ 1ee60880), WP 7.1.2, TT5, wp-env on :9451.

Method: six read-only code reviewers (interactive blocks, forms, query family,
extensions, layout/content blocks, admin/REST/PHP) plus live browser testing
with Playwright. Every finding is tagged with how it was established:

- **[live]** reproduced on the running site
- **[code]** confirmed by reading the code path myself
- **[review]** reported by a reviewer from a code trace; not independently verified

## Status — branch `claude/bug-hunt-fixes`

Fixed and re-verified live on WP 7.1.2 (build, lint, PHPStan, 4,606 JS unit tests, 2,334 PHPUnit tests all green):
Tier 1 #1–#9, plus: accordion close/reopen race; duplicated blocks keep `uniqueId`
(`useUniqueBlockId` now re-seeds a just-inserted copy; accordion-item, counter,
image-accordion-item and tab moved onto it); tabs `aria-labelledby` + skip link
outside the tablist; counter `0` / prefix-suffix; form 429 handling, Turnstile reset,
array-valued fields, `{page_url}`; query `bindSearchTo` arrays and load-more context
on first paint after page 1; grid span / mobile order / hover effects on dynamic
blocks; text-alignment inheritance runs on insert only.

New shared helper: `src/hooks/useWasJustInserted.js`. It is the guard for any mount
effect that rewrites attributes "on insert".

Not bugs on closer look: the Form Builder repairing duplicate `formId`s on open is
deliberate (server resolves settings by ID); the core Spacer converting height to
flex size in a flex parent is core behaviour.

Everything below without a ✅ is still open.

## Tier 1 — fix first (✅ all fixed on the branch above)

## Tier 2 — real user-facing bugs

### Interactive blocks
- **Accordion**: closing and then reopening within 350 ms leaves `aria-expanded="true"` with a hidden panel. The close `setTimeout` is never cancelled. `accordion/view.js:305-318` — [live]
- **Duplicated blocks keep `uniqueId`** → duplicate HTML ids (accordion-item header/panel, tab panel/button, hotspot tooltip, counter). Modal warns about this; the others don't. `useUniqueBlockId` and the inline copies only seed when the value is empty. — [live] `duplicateBlocks` copies the id; smoke page has `id="counter-1o901ccay"` ×2
- **Tabs**: with an anchor set, the button id becomes `tab-{anchor}` but the panel's `aria-labelledby` stays `tab-{uniqueId}` → broken reference. Fix in view.js by setting `aria-labelledby` from the generated button id. `tabs/view.js:186`, `tab/save.js:38-40` — [live]. Also: the skip link is a child of `role="tablist"` (invalid ARIA children).
- **Counter**: an end value of `0` renders `100` (`|| 100`), and a duration of `0` becomes 2 s. `counter-group/view.js:102, 106, 171` — [code]
- **Counter**: the reduced-motion / CountUp-failure path drops the prefix and suffix ("$1,250+" → "1,250"). `counter-group/view.js:165-194` — [code]
- **Expanding background**: blur `0` → 30 px. **Parallax**: speed `0` → 5. Both use `||` defaults. `expanding-background/editor.js:139`, `frontend.js:156`; `vertical-scroll-parallax/frontend.js:65-67` — [review]
- **Google Maps**: Silver/Dark styles are ignored because a `mapId` is always set. `map/handlers/googlemaps-handler.js:148-160` — [review]
- **Image accordion**: Enter/Space on a link inside an item is swallowed (keydown has no target guard). `image-accordion/view.js:177-182` — [review]
- **Timeline**: stagger delay uses the absolute item index, so item 20 waits 2 s after scrolling into view. `timeline/view.js:96-97` — [review]
- **Scroll Slides**: the desktop/mobile engine is chosen once at init, so a rotate or resize across 781 px breaks it. `scroll-slides/view.js:45-77` — [review]
- **Table of Contents**: `isManualNavigation` is never set to `true`, so the scroll-spy fights click navigation. The `aria-label` "Jump to section" is hard-coded English. — [review]

### Forms
- **Rate-limit 429s are treated as "host blocks REST"**: one too-fast submit triple-posts, then forces native POST for the rest of the session. `form-builder/view.js:627-629, 667-670` — [code]
- **Turnstile token not reset after a failed submit** → "Security verification failed" until reload. `view.js:729` — [review]
- **Blank number field stored as `0`**, and a blank *required* number passes server validation. `class-form-handler.php:873-874` — [code]
- **`{page_url}`** in emails is the endpoint (`/wp-json/...` or `admin-ajax.php`), not the page. `class-form-handler.php:1157-1162` — [code]
- **Field ids are not scoped to the form** (`id="field-email"`), so two forms on a page cross-wire their labels and `aria-describedby`. — [review]
- Server phone/URL validation is stricter than the browser's (e.g. `555.123.4567` is rejected only after the round trip). — [review]
- Admin submissions: "Sent:" is always blank (`wp_date()` given a MySQL string), and "Submitted:" is shifted by the UTC offset. `class-form-submissions.php:~208-218` — [review]
- An array-valued field (`value:["x"]`) → TypeError 500 instead of 400. — [review]
- Retention cleanup deletes 100 per day max and compares a GMT cutoff with local `post_date`. — [review]

### Query
- `excludeCurrent` and `source: current` are ignored on AJAX refresh/load more (no queried object in REST). `render-posts.php:377, 477-482` — [review]
- Anonymous visitors still get a REST nonce from the filter and pagination blocks, against the documented design, so stale-nonce failures hit cached pages. `query-filter/render.php:600`, `query-pagination/render.php:96, 157` — [review]; nonce present in the markup observed [live]
- Woo params (`min_price`, `max_price`, `rating_filter`, `query_type_*`) are dropped on AJAX refresh. `class-query.php:666`, `view-helpers.js:345-372` — [review]
- `offset` inflates `totalItems`/`totalPages` → empty pages, and No Results stays hidden. — [review]
- Filter counts ignore `include_children` while the query includes children. — [review]
- Focus is lost after every filter interaction (region `innerHTML` swap). — [review]
- `?filter_category=a,b` ticks both boxes, but the query searches for slug `ab`. — [review]

### Layout / content
- **Patterns overflow at 390 px**: `content-brand-trust-bar`, `content-client-logos`, `content-trust-companies`, `homepage-agency`, `homepage-portfolio` and `homepage-saas` use a `nowrap` Row of x-large wordmarks, so the page scrolls sideways (475 px document at a 390 px viewport). — [live] on pages 1711 and 1751
- **Dynamic Image** `editorStyle` points at `editor.css`, which the build never emits, so it has no editor styles. `dynamic-image/block.json:88` — [review]
- **Icon List** parent settings (size, colour, position) come from context in item `save()`, which has no context, so they never reach the frontend. — [review]
- **Breadcrumbs**: the focus ring is clipped by `overflow:hidden`; non-public ancestors leak into the trail and the JSON-LD; nothing renders on archive, search or 404 templates. — [review]
- **Blobs** reset to default blue after bfcache or soft-nav re-init. `blobs/view.js` — [review]
- **Icon**: decorative + link → a focusable link with no accessible name. — [review]

### Extensions / editor
- **Text-alignment inheritance** guard is keyed on `props` (new each render), so it runs on every mount: it dirties posts and re-applies the alignment after a user clears it. `text-alignment-inheritance/index.js:80-101` — [code]
- **Max-width lazy HOC** (`Suspense` fallback → primary) remounts every block once when its chunk loads. — [review]
- `dsgoVisibility` / `dsgoStyleBinding` are registered on excluded blocks too (JS ignores `excluded_blocks`; PHP honours it). — [review]
- Grid span / mobile order look up the *outermost* grid, not the direct parent. — [review]
- The custom CSS `on\w+=` strip has no word boundary, so `[data-config=1]` → `[data-c]`. — [review]

### Admin / PHP
- `get_settings()` merges shallowly, so after a partial save nested defaults vanish from the UI. `class-settings.php:356` — [review]
- llms.txt: the physical file is rewritten on **every** `save_post` of any type, including anonymous form submissions; settings changes leave it stale; uninstall deletes `ABSPATH/llms.txt` rather than the home path. — [review]
- The Accept-header negotiation returns 406 for `application/json` and similar Accept headers on front-end pages. — [review]
- `uninstall.php` leaves the filter-index table, a number of options, transients, post meta, cron events, and draft-copy posts. — [review]
- Patterns are registered only on admin/REST requests, so a `core/pattern` block that references a DSGo pattern renders empty on the frontend. `includes/patterns/class-loader.php:73-77` — [review]
